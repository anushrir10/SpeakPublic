The Technical Blueprint

How we replace complex machine learning infrastructure with smart AI orchestration

🧠

Precomputed AI Caching

NCERT textbooks are static. Instead of calling AI models dynamically per user, we generate concepts, flashcards, translations, and voice files once at build time. We store them in Cloudflare R2 and query them in milliseconds. Per-user LLM runs are only triggered for custom highlights.

🚀

FSRS Adaptive Engine

We skip custom spaced repetition systems and employ the modern FSRS (Free Spaced Repetition Scheduler) mathematical model. It yields better memory retention and recall stability than legacy algorithms (like SM-2) and syncs instantly to PostgreSQL tables.

⚡

Claude Prompt Optimizations

Using Claude 3.5 Sonnet's prompt caching features, we pin textbook chapters and system instructions directly into Anthropic's memory. This delivers a 90% reduction in input token pricing and results in sub-second generation times for simplified summaries.
